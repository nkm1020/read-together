# Read Together 1안

design-taste-frontend 스킬로 만든 1안이에요. 홈(모집)은 정적 페이지고, 회차·랭킹·배틀 화면은 Supabase에 실제로 저장된 기록을 보여 줘요.

## 파일

| 파일 | 주소 | 내용 |
| --- | --- | --- |
| `index.html` | `/` | 홈(모집) |
| `sessions.html` | `/sessions` | 회차, 인상 깊은 문장 남기기 (로그인) |
| `ranking.html` | `/ranking` | 확정된 배틀 점수의 누적 랭킹 |
| `battle.html` | `/battle` | 멤버 휴대폰 화면: 로그인 → 입장 코드 → 받아쓰기 제출 |
| `me.html` | `/me` | 내 정보: 참여·점수·순위·커피 요약, 배틀 기록, 남긴 문장, 이름 바꾸기 (로그인) |
| `dashboard.html` | `/dashboard` | 프로젝터 화면: 실시간 순위 (운영진으로 로그인하면 입장 코드도 보여요) |
| `js/admin.js` | 주소 없음 | 관리자 화면: 운영(회차·참여 체크·클립·멤버 명단·점수 확정)과 배틀 진행 |
| `vercel.json` | | `.html` 없이 짧은 주소로 열리게 해요 (`cleanUrls`) |
| `supabase/schema.sql` | | DB 테이블, 접근 규칙, 채점 함수 (실행함) |
| `supabase/002_optional_dates.sql` | | 화·수 날짜 중 하나만 있어도 되게 (실행함) |
| `supabase/003_phone_login.sql` | | 휴대폰 번호 로그인, 참여 기록 (실행함) |
| `supabase/004_member_rename.sql` | | 멤버가 자기 이름만 바꾸는 함수 (실행함) |
| `supabase/005_group_articles.sql` | | 화·수 그룹이 다른 원문을 읽게: 회차마다 그룹별 원문, 문장도 그룹별로 (**아직 실행 안 함**) |
| `js/config.js` | | Supabase 주소와 공개 키 |

관리자 화면은 따로 주소가 없어요. 운영진 번호로 로그인하면 메뉴바에 **관리자** 버튼이 생기고, 누르면 지금 보던 페이지 자리에 열려요. 주소를 숨기는 건 보안이 아니라 정리일 뿐이고, 누가 무엇을 바꿀 수 있는지는 데이터베이스 규칙이 막아요.

## 로그인

- 멤버는 신청 폼에 적은 휴대폰 번호로 로그인해요. 숫자만 눌러도 `010-1234-5678`처럼 줄표가 저절로 들어가요. 운영진이 멤버 명단에 번호를 넣어 둔 사람만 들어올 수 있어요.
- 처음 로그인할 때 비밀번호(6자 이상)를 정해요. 다음부터는 번호와 비밀번호로 들어와요. 로그인은 90일 동안 유지돼요.
- 비밀번호를 5번 틀리면 10분 동안 잠겨요. 잊어버리면 관리자 → 멤버 명단 → **초기화**를 누르면 다음 로그인 때 새로 정해요.
- 로그인하면 메뉴바의 내 이름을 눌러 **내 정보**(`/me`)로 가요. 표시 이름은 여기서 직접 바꿀 수 있어요. 그룹과 활동 여부는 운영진만 바꿔요.
- 문장 남기기와 배틀 점수는 로그인한 사람 이름으로만 저장돼요. 다른 사람 이름으로는 남길 수 없어요.
- 비밀번호는 bcrypt로 바꿔서 저장하고, 로그인 키도 해시로만 남겨요. 번호 목록은 운영진 말고는 읽을 수 없어요.

## 처음 한 번

1. 사이트에서 **로그인** → 운영진 번호(`003_phone_login.sql` 끝에서 데이터베이스에 넣은 번호)를 넣고 비밀번호를 정해요.
2. 메뉴바의 **관리자** → 멤버 명단에서 **한 줄 추가** → 내 이름과 그룹, 같은 운영진 번호를 넣고 **명단 저장**. 그러면 운영진 번호가 내 멤버 기록과 연결돼서 나도 문장을 남기고 배틀에 들어갈 수 있어요.
3. 신청 폼 응답을 보고 멤버마다 이름, 그룹, 휴대폰 번호를 넣어요. 다른 운영진이 있으면 그 줄의 **운영진**을 켜요.
4. 첫 회차와 Dictation 회차의 클립, 정답 스크립트를 넣어요.

## 회차마다

- **원문**: Reading 회차는 화요일과 수요일 그룹이 다른 원문을 읽어요. 관리자 → 운영 → 회차에서 날짜를 넣은 그룹마다 원문 칸이 열려요. 같은 원문이면 **화요일 원문 그대로 쓰기**를 누르세요. 문장도 그룹별로 모이고, 다음 회차의 그 그룹 모임이 시작되면 마감돼요. 회차 페이지 위의 **화요일 그룹 / 수요일 그룹**으로 바꿔 볼 수 있고, 로그인한 멤버는 자기 그룹이 먼저 보여요. Dictation 클립은 두 그룹이 같이 써요.
- **참여 체크**: 관리자 → 운영 → 회차 표의 **n명 체크** → 온 멤버를 체크하고 저장. 배틀에 입장한 멤버는 자동으로 체크돼요.
- 회차 페이지의 모든 회차 표에 회차마다 참여 인원이 보여요.

## 배틀 진행

1. 노트북에서 로그인 → **관리자** → **배틀 진행** → 회차와 그룹을 고르고 **배틀 열기** → 네 자리 입장 코드가 생겨요.
2. **프로젝터 화면 열기**로 대시보드를 띄워요.
3. 멤버는 휴대폰으로 `/battle`에서 로그인하고 코드를 넣어 입장해요.
4. **라운드 시작** → 클립을 두 번 들려주고 → **라운드 종료하고 채점**. 마지막 라운드 뒤 **배틀 끝내기**.
5. 운영 탭의 **점수 확정**을 누르면 랭킹과 커피 기록에 더해져요.

고친 내용을 다시 올릴 때는 이 명령을 쓰세요. 1안 폴더 경로를 넣어 뒀기 때문에 어느 폴더에서 실행해도 1안만 올라가요.

```bash
vercel deploy "/Users/kangmin/Documents/학교/동아리/read together/1안" --prod --yes
```

상위 폴더(`read together`)에서 경로 없이 `vercel deploy`를 실행하면 2안과 작업 파일까지 통째로 올라가고 첫 화면이 404가 돼요.

`.vercelignore`가 작업 파일(`.taste-skill`, `.gstack`, `supabase/`, 이 README)은 올리지 않게 막아요.
